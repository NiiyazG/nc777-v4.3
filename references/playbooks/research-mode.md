# Research Mode — Diverge → Converge → Sharpen

Load only for vague ideas, product/architecture exploration, or when multiple fundamentally different directions are plausible.

## Diverge
Generate 3–5 materially different options, not cosmetic variants. Useful lenses:
- simplest / least moving parts;
- lowest risk / most reversible;
- lowest cost / shortest path;
- most scalable;
- closest existing pattern;
- 10× assumption change;
- inversion (what if the apparent constraint is removed/reversed?).

## Converge
Compare only decision-relevant trade-offs: user value, implementation cost, operational burden, reversibility, security/data risk, migration path, evidence uncertainty.

## Sharpen
Return:
- recommended direction and why;
- smallest MVP/vertical slice;
- explicit Not Doing;
- major unknowns/risks;
- what evidence would change the recommendation.

Do not force research mode on well-specified implementation tasks.
